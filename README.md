# Bangalore House Price Prediction

## Project Overview
This project predicts Bangalore house prices using Machine Learning regression techniques.
The dataset is cleaned, processed, and analyzed using Python libraries such as Pandas, NumPy, and Matplotlib.

---

## Features
- Data Cleaning
- Feature Engineering
- Outlier Removal
- Price Per Square Feet Calculation
- Dimensionality Reduction
- Data Visualization
- Regression-Based Prediction

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Flask

---

## Dataset
Dataset used:
Bengaluru House Price Dataset

---

## Project Workflow
1. Load Dataset
2. Handle Missing Values
3. Convert Total Square Feet Values
4. Feature Engineering
5. Remove Outliers
6. Build Clean Dataset
7. Visualize Data
